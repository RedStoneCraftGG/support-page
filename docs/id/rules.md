# Peraturan Server

Halaman ini menjelaskan peraturan server Venity Network yang wajib dipatuhi oleh seluruh pemain. Peraturan ini dibuat untuk menjaga kenyamanan, keamanan, dan keadilan di dalam server.

## 1. Dilarang Menggunakan Cheat atau Segala Jenis Modifikasi Client

Penggunaan cheat, hack, atau modifikasi client yang memberi keuntungan tidak adil (seperti x-ray, hitbox, fly hack, esp, dan modul curang lainnya) sangat dilarang. Jika anda tertangkap menggunakan cheat, maka anda akan segera terkena banned dan wajib menunggu durasi waktu banned sampai habis.

Jika anda merasa tidak menggunakan cheat, tetapi anda terkena banned. Silahkan hubungi staff atau admin Venity Network di [Discord](https://venitymc.com/discord)

## 2. Dilarang Mengeksploitasi Bug

Jika menemukan bug atau kesalahan di server, laporkan kepada staff. Eksploitasi bug untuk keuntungan pribadi akan dikenai sanksi.

## 3. Dilarang Spam dan Menggunakan Bahasa Kasar

Dilarang mengirim pesan berulang kali dalam waktu singkat atau menggunakan kata-kata kasar dan tidak pantas di chat server (dalam bahasa apapun).

::: info
Jika orang yang melanggar berada di dalam chat guild, maka itu adalah tanggung jawab officer guild dan pemimpin guild.
:::

## 4. Hormati Sesama Pemain dan Staff

Selalu bersikap baik dan menghormati pemain lain serta tim staff server. Bullying, pelecehan, atau perilaku merendahkan **tidak akan ditoleransi**.

## 5. Dilarang Mempromosikan Modifikasi Client Illegal atau Cheat

Pemain dilarang mempromosikan atau menyarankan penggunaan modifikasi client yang ilegal atau tidak diizinkan oleh server. Modifikasi yang memberi keuntungan tidak adil sangat dilarang keras.

## 6. Gunakan Akun Sendiri

Jangan berbagi akun dengan pemain lain atau menggunakan akun orang lain. Akun yang digunakan oleh lebih dari satu orang bisa dikenai sanksi.

## 7. Dilarang Membuat Keributan di Komunitas server

Pemain dilarang membuat keributan atau kekacauan di komunitas server, baik melalui chat server, forum, Discord, atau platform komunikasi lain yang terhubung dengan server. Ini termasuk memprovokasi, menyebarkan informasi palsu, membuat konflik antar pemain, atau melakukan spam. Perilaku ini mengganggu kenyamanan pemain lain dan dapat menyebabkan tindakan tegas dari tim staff.

## 8. Jangan Menyebarkan Informasi Pribadi

Untuk menjaga keamanan, dilarang membagikan informasi pribadi (seperti alamat, nomor telepon, dll.) milik sendiri atau orang lain di dalam server.

## 9. Kewajiban Membaca dan Mematuhi Peraturan Tambahan

Server mungkin memiliki peraturan tambahan atau sementara untuk kondisi tertentu. Pastikan untuk selalu mengikuti update terbaru dan mematuhinya.

## 10. Pelanggaran Berulang Akan Ditindak Tegas

Pemain yang melanggar peraturan berkali-kali atau melakukan pelanggaran serius dapat di banned secara permanen dari server
